# GPM Haweli Mess Website

## Files
- `index.html` — main website
- `style.css` — design and responsive styling
- `script.js` — today's menu + weekly menu + WhatsApp button
- `assets/college.jpg` — supplied college photo
- `assets/rizwan.jpg` — supplied DP

## IMPORTANT: WhatsApp number
Open `script.js`, find:
`const number = "91XXXXXXXXXX";`
and replace it with the actual WhatsApp number, including country code, without `+` or spaces.

Example:
`const number = "919876543210";`

## Run on phone
You can open `index.html` in a browser, or use a simple local server/code editor app.

## GitHub Pages
1. Create a GitHub repository.
2. Upload all files and the `assets` folder.
3. Open Settings → Pages.
4. Choose the main branch/root folder and save.
5. GitHub will give you the public website link.

## Cartoon food illustrations
Each meal card uses a custom pastel cartoon-style SVG food illustration matching the routine (puri, litti, sattu puri, bhature, rice/dal, roti-sabji, chicken, fish, aloo paratha, samosa/papad/sewai etc.).
